🔑 관리자 인증
📌 이미지 URL 가져오는 법
어떤 사이트든 공통
이미지 위에서 우클릭 → "이미지 주소 복사" (Chrome) / "Copy Image Address"
이미지 자체의 URL이어야 합니다 (.jpg .png .webp 로 끝나거나 CDN URL)

🔵 Unsplash — unsplash.com에서 검색 → 이미지 클릭 → 우클릭 → 이미지 주소 복사
예시: https://images.unsplash.com/photo-1506905925346-21bda4d32df4?...

🟢 Pexels — pexels.com에서 검색 → 이미지 클릭 → "Free Download" 옆 화살표 → "Large" 선택 후 링크 주소 복사
예시: https://images.pexels.com/photos/1234/photo.jpeg?...

🟡 Wikimedia Commons — commons.wikimedia.org → 이미지 찾기 → "원본 파일" 링크 우클릭 → 주소 복사
예시: https://upload.wikimedia.org/wikipedia/commons/...

⚠️ 주의 — HTML 페이지 URL(주소창 URL)이 아닌 이미지 파일 URL이어야 합니다
